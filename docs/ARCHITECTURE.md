# UniTest — архитектура

Рабочее название: **UniTest**. Система создания и проведения тестов в автономном и сетевом режимах на общем формате `.quiz` и общем движке оценивания.

## Цели архитектуры

1. Один тест — два режима: автономный пакет и сетевая сессия без повторного создания.
2. Декларативный формат теста: без исполнения кода из `.quiz`.
3. Единый JavaScript-движок `quiz-engine` без зависимостей от DOM/PHP/MySQL.
4. Сервер преподавателя — авторитетный источник времени и прав в сетевом режиме.
5. Автономный плеер не требует PHP и MySQL.

## Решение по backend-стеку (Этап 1)

**Выбрана модульная структура на чистом PHP 8.3+**, а не Laravel.

Причины:

- В окружении OSPanel Composer (2.4-dev, 2022) устарел относительно актуального Laravel; установка полного каркаса усложняет Этап 1.
- Требования ТЗ (контроллеры, сервисы, маршрутизация, миграции, централизованные ошибки) реализуются без фреймворка.
- Структура каталогов совместима с последующей миграцией на Laravel при необходимости.

Пересмотр решения возможен, если появится актуальный Composer и это упростит auth/валидацию на поздних этапах.

## Единый формат и версионирование

- Файл `.quiz` — ZIP + `manifest.json` + `resources/` (см. `QUIZ_FORMAT.md`).
- В БД тест хранится как метаданные `quizzes` + неизменяемые снимки `quiz_versions`.
- Сетевая сессия всегда ссылается на `quiz_version_id`, а не на «живой» черновик.
- Движок и правила оценивания имеют собственные версии (`engineVersion`, `scoringVersion`).

## Режимы работы

### Автономный

1. Экспорт снимка теста в пакет под целевую ОС (Windows / macOS / Linux).
2. Приоритет v1: приложение с встроенным тестом (модель MyTestX).
3. Дополнительно: портативный плеер + внешний `.quiz`.
4. Результат — локальный `.result` (JSON + контрольная сумма), импорт в систему преподавателя.

### Сетевой

1. Локальный PHP-сервер на машине преподавателя.
2. Ученики — только браузер (IP:порт или код занятия).
3. Сессия, участники, попытки и ответы — в MySQL.
4. Realtime на первом этапе — polling API.

Подробности: `NETWORK_MODE.md`.

## Frontend

- HTML5 / CSS3 / JS ES modules.
- Vite для сборки.
- TypeScript допустим для `quiz-engine` и крупных модулей.
- Локализация: русский в v1, ключи i18n с Этапа 3.

## Безопасность (базовые принципы)

- Пароли только как хеши (`password_hash`).
- Параметризованные PDO-запросы.
- CSRF для cookie-сессий web UI.
- Rate limit на join по коду занятия.
- Валидация ZIP (ZIP Slip, размеры, типы).
- Клиентским баллам в сетевом режиме не доверять: сервер пересчитывает через тот же контракт правил (порт правил на PHP или вызов проверенного снимка ответов + серверный scoring).

На Этапе 2–5 будет зафиксирован конкретный способ серверного scoring (порт правил в PHP vs общий JSON-контракт + дублирование логики с тестами эквивалентности).
